Custom Font Files Directory
=============================
Place your purchased/downloaded font files here:

Marenao Typeface (by Designstag):
- Marenao-Bold.otf (or .woff2, .ttf)
- Marenao-SemiBold.otf (or .woff2, .ttf)
- Marenao-Medium.otf (or .woff2, .ttf)
- Marenao-Regular.otf (or .woff2, .ttf)
- Marenao-Light.otf (or .woff2, .ttf)

Ghostac Typeface:
- Ghostac.otf (or .ttf, .woff2)

NewBlack Typeface:
- NewBlack-Regular.woff2 (or .otf, .ttf)
- NewBlack-Bold.woff2 (or .otf, .ttf)

Grift Font Family:
- Grift-Regular.woff2 (or .otf, .ttf)
- Grift-Bold.woff2 (or .otf, .ttf)

The CSS @font-face rules in /public/fonts/marenao.css and src/styles/tokens.css are already set up to load Marenao automatically from this directory!
